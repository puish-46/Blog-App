# Week 7 - Full Stack Blog App

## Overview

A full-stack Blog Application built with React (frontend) and Node.js + Express + MongoDB (backend). Supports three roles — **User**, **Author**, and **Admin** — each with different permissions.


## Concepts Covered

- **Role-Based Access Control** — User, Author, Admin roles
- **JWT Authentication** — login, token stored in cookies
- **Protected Routes** — middleware on backend, `ProtectedRoute` on frontend
- **React Router** — multi-page navigation
- **Zustand** — global auth state management
- **Mongoose** — MongoDB schemas for Users and Articles
- **CORS & Cookie Parser** — cross-origin requests with credentials
